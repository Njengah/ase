### 1. Interactive Profile Card Demo
**Location**: `interactive-card-demo/`
**Technologies**: HTML, CSS, JavaScript

A beginner-friendly demo showcasing:

- Dynamic theme switching
- Responsive design

Perfect for learning fundamental web development concepts!

[View Demo →](./interactive-card-demo/)

## Getting Started

Each demo is self-contained and can be run independently:

1. Navigate to the demo directory
2. Open `index.html` in your web browser
3. No build tools or installation required!
