# Interactive Profile Card Demo

A simple, interactive profile card built with pure HTML, CSS, and JavaScript. This project demonstrates fundamental web development concepts including CSS animations, DOM manipulation, and event handling.

## Features

- **3D Card Flip Animation**: Click the card to flip it and reveal more information
- **Dynamic Theme Switching**: Change the color theme with a single click
- **Responsive Design**: Works seamlessly on desktop and mobile devices
- **Smooth Animations**: CSS transitions and keyframe animations for a polished look
- **Keyboard Accessible**: Navigate and interact using keyboard controls

## What You'll Learn

This demo showcases:

1. **HTML Structure**
   - Semantic HTML elements
   - SVG graphics for the profile icon
   - Proper document structure

2. **CSS Techniques**
   - CSS Grid and Flexbox for layout
   - CSS Custom Properties (variables) for theming
   - 3D transforms and perspective
   - Keyframe animations
   - Responsive design with media queries
   - Gradient backgrounds

3. **JavaScript Functionality**
   - DOM manipulation
   - Event listeners
   - CSS class toggling
   - Dynamic style updates
   - Keyboard event handling

## How to Run

1. Clone this repository
2. Navigate to the `projects/interactive-card-demo` directory
3. Open `index.html` in your web browser

No build tools or dependencies required!

## Usage

- **Flip the Card**: Click anywhere on the card or press Enter/Space when focused
- **Change Theme**: Click one of the theme buttons below the card
- **View Details**: The back of the card shows a bio and skill tags
